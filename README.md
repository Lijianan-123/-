# Video Downloader Demo

说明
- 这是一个演示项目：前端提交视频链接到后端，后端使用 yt-dlp 解析并把视频流式返回给浏览器以供下载。
- 仅作学习/测试用途。请确保遵守目标平台的使用条款与版权法。

运行（使用 Docker）
1. 构建镜像：
   docker compose build

2. 启动服务：
   docker compose up -d

3. 打开浏览器访问：
   http://<server-ip>:3000

注意
- yt-dlp 与 ffmpeg 已在镜像内安装。某些视频需要先下载音频与视频流再合并，yt-dlp 会处理大多数情况，但在流式输出（-o -）下可能无法完成合并，这时需要修改实现：先把文件下载到临时目录，再用 ffmpeg 合并，再返回文件。
- 生产环境请：
  - 添加认证/速率限制/验证码以防滥用。
  - 不要允许匿名无限制下载。
  - 使用 HTTPS（通过反向代理如 nginx/Traefik）。
  - 定期清理临时文件，限制最大并发与文件大小.
